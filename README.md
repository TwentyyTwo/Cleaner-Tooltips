<h4 align="center">A simple client-side mod that changes the tooltips of tools and armor to display their attributes as icons.</h4>

## Additional Features

- Display the durability of items (disabled by default)
- Compare the attributes of equipped and hovered over items
- Sharpness increases the attack damage (Fixes [MC-271840](https://bugs.mojang.com/browse/MC/issues/MC-271840))
- Display the mining speed of tools (disabled by default)
- The textures and rendering/calculation logic is fully resource pack driven

## Compatibility
Cleaner Tooltips should be compatible with most mods affecting the UI, including:

- BetterCombat - Adds the attack range next to the attributes.
- Legendary Tooltips
- Equipment Compare
- Tooltip Overhaul
